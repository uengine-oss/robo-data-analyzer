# spec 101 — 분기 귀속 근거성 게이트 (측정 전용)

## 왜

감사(`docs/핸드오프/analyzer-성능/05`)가 24함수 층화 표본에서 **환각 29건·누락 25건**을 확정했다.
빌드 계획(`08`)은 착수점으로 "근거성 span 게이트(B) — 규칙의 코드 심볼을 라이브 소스에 역매칭,
임계 29건 중 25건(85%)"을 지목했다.

**착수 전 실측이 그 설계를 반증했다.** 프롬프트가 `given/when/then` 에 변수·메서드 토큰을 금지하고
도메인 코드값 리터럴만 허용한다(`code_rules_examples` 프롬프트 자가점검 절). 그래서 산출물은
한국어 산문이고, 순수 span 역매칭이 잡을 수 있는 것은 **주석 전용 식별자 소수**뿐이다
(실측: 24함수 304항목 중 순수 provenance 플래그 82건, 그 중 대부분이 `SMS`·`VAN`·`EDI` 같은
주석 유래 도메인 약어 오탐).

29건을 유형별로 분해하면 지배적 결함은 "소스에 없는 심볼"이 아니라 **분기 귀속 오류**다:

| 유형 | 건수 | 예 |
|---|---:|---|
| 값집합·디스패치 병합/날조 | 9 | `op_cl ∈ ['11','14','21','31'] → 한 규칙` (11·14→c200, 21·31→c900) |
| 분기 밖 로직 혼입(교차오염) | 6 | `'E'` 가지에 `'F'` 가지의 조회맵·필드를 결합 |
| 주석·죽은코드 유래 | 4 | 주석 처리된 `pay_mthd_cd` 를 "기록 필드"로 |
| 위임 함수인데 규칙 생성 | 2 | 분기 0 + 호출 2개인데 callee summary 로 규칙 작성 |
| 가드 누락 | 1 | 바깥 `gc_edi_fb_cl_cd=="X"` 게이트를 떨어뜨림 |
| 의미 반전·과잉일반화 등 | 7 | 매핑 Y↔N 반전 |

따라서 게이트 B 를 **"소스에 있나"가 아니라 "그 분기에 있나"** 로 재정의한다. 재료는 이미 있다
(`control_subtree` = IF/ELSE/SWITCH/CASE 줄범위 트리, spec 069).

## 무엇을

`RulesExamplesOutput` 을 결정론으로 검사해 **근거성 위반 findings 를 산출**한다. LLM 재호출 0.

### 범위 (이번 슬라이스)

- **측정 전용**. 산출물을 바꾸지 않는다. findings 는 로그와 `fn.extra["grounding_findings"]` 에만 남는다.
- 결정론 산출 6종과 완주 수를 정확히 보존한다.

### 비범위

- 교정·재추출·재호출 (임계 통과 후 별도 spec)
- 행위 등가 검증 (실행 없이 불가 — `08 §4`)
- LLM judge (약 MoE 로 단독 게이트 불가 — `08 §4`)
- 누락(coverage gap) 판정 — 분기 대장 게이트 A 의 몫

## 검사 5종

입력: `code_body`(라우틴 상대 1-based 줄), `control_subtree`, `RulesExamplesOutput`, 언어.

| id | 이름 | 판정 | 겨냥 |
|---|---|---|---|
| `delegation` | 위임 함수 규칙 생성 | 분기 노드 0 + 호출 ≥1 인데 `rules` 비어있지 않음 | 위임 2건 |
| `value_set` | 값집합 대장 불일치 | 조건절이 열거한 코드값 집합이 (a) 실제 분기 라벨에 없는 값을 포함하거나 (b) 서로 다른 효과(callee 집합)를 가진 라벨을 한 항목에 병합 | 값집합 9건 |
| `branch_scope` | 교차 분기 오염 | 한 항목의 원자들이 **서로 배타적인 형제 분기**에 나뉘어 존재 | 교차오염 6건 |
| `guard` | 조상 가드 누락 | 항목이 귀속된 분기의 조상 가드 조건 리터럴이 항목에 전무 | 가드 1건 |
| `dead_span` | 죽은 근거 | 필드성 식별자(밑줄 포함 또는 심볼 목록 소속)가 활성 코드에 없고 주석·비활성 블록에만 있거나 어디에도 없음 | 주석 4건 |

### 범용성 계약

- 게이트 로직에 언어·프로젝트·엔진·명명규약 분기를 두지 않는다.
- 언어별로 필요한 것은 **주석·문자열 구문 표(데이터)** 뿐이며 `pipeline/ontology_roles.yaml` 의
  `source_lexicon` 에 둔다. 새 언어 = 표 한 줄.
- 분기 노드 타입 목록은 이미 같은 파일의 `roles.control_structure` 가 소유한다(중복 정의 금지).
- 어휘가 없는 언어는 **조용히 통과하지 않고** 명시적으로 실패한다.

### 임계가 도달 불가인 이유 (설계 결함이 아니라 대상의 성질)

29건 중 **최소 6건은 결정론 신호가 원리적으로 0** 이다 — 코드값도 분기 참조도 전부
근거가 있고, **대응·방향만 반대**다:

| 항목 | 성질 |
|---|---|
| b320 ×3 | 인접 분기의 로직을 다른 분기로 옮겨 서술 / `when` 서술이 코드와 반대 |
| b400 "~에 따라" | 무조건 대입을 조건처럼 서술. 텍스트에 코드 원자 자체가 없음(순수 산문) |
| 10101 b200 | `Y→146633 / else→114` 를 정확히 뒤집음. 값 4개 모두 활성 코드에 존재 |
| d010 | `'XXXX'` 세팅을 없는 경로에 귀속. 그 값은 다른 분기에 실재 |

따라서 결정론 게이트의 상한은 **23/29(79%)** 이며, 남은 미검출 6건을 다 잡는 추가 검사
(op 어휘 대조 · 코드값 dead span · 분기 결과(return) 대조)를 전부 붙여도 **85% 에 못 닿는다.**

08 의 임계 85% 는 29건의 **유형을 분해하기 전에** 정해졌다. "코드에 없는 심볼"이 지배적일
것이라 가정했으나, 실제 지배 유형은 "분기 귀속 오류"와 "의미 반전"이었다.

### 그래도 남는 사실

- `value_set`(값집합·디스패치 병합/날조)은 **오탐 0 · gold 9건 중 6건 적중**으로 유일하게
  정밀·재현이 함께 선 검사다. 재도전한다면 이것 하나만 별도 슬라이스로 승격할 값이 있다.
- `guard` 는 findings 의 절반을 차지하면서 독립 적중이 거의 없다 — 제품에 넣으면 안 된다.
- `delegation`(분기 0 + 호출뿐인데 규칙 생성)은 1함수 2항목을 정확히 잡았고 오탐 0이다.
