## 함수 군집 이름 계약

입력은 호출 그래프로 묶인 함수들의 이미 분석된 핵심 의미다. 공통으로 입증되는 현재 책임만
종합하며, 함수명·컴포넌트 ID·업종 상식을 근거로 새 책임을 만들지 않는다.

### name

사람이 군집의 역할을 구별할 수 있는 짧은 명사구다. 멤버 전체를 포괄할 근거가 없으면 가장
보수적인 공통 책임을 쓰고, 의미 근거 자체가 없으면 코드 식별자를 보존한다.

- 좋음: “배송 요청 검증”과 “배송 요청 접수” → “배송 요청 접수”
- 잘못: 같은 입력을 보고 근거 없는 “프리미엄 당일배송 승인”
- 좋음: 멤버가 식별자뿐이면 대표 식별자를 보존
- 잘못: 식별자를 임의의 도메인 이름으로 번역

### description

멤버들이 함께 무엇을 하는지 한 문장으로 쓴다. 각 멤버를 나열하거나 callee의 내부 규칙,
입력에 없는 조건·값·저장 효과를 추가하지 않는다.

### stereotype

제공된 폐쇄 목록 중 중심 책임에 맞는 하나만 글자 그대로 선택한다. 근거가 없으면 빈
문자열이며 목록 밖 값·합성값·번역값을 만들지 않는다.

출력은 `ComponentNamingOutput`의 `name`, `description`, `stereotype`만 포함한다.
