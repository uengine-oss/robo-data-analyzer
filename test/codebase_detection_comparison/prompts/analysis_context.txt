다음은 자동 수집된 코드베이스 증거다. 이 정보 + 도구 (grep / read_file / read_function) 로
**프레임워크 패턴** 과 **DB 접근 패턴** 만 확정해라.

## 진행 방침

- 목적은 **패턴** 확정. 테이블 전수 수집 아님.
- 수집 컨텍스트 (매니페스트·import·뼈대·리소스 미리보기) 만으로 패턴이 명확하면 도구 호출 없이 바로 출력.
- 불명확할 때만 도구 사용: XML/설정이면 `read_file`, 소스 함수면 `read_function`, 넓은 검색은 `grep`.
- **확정 조건**: 호출 방식 1~2 개 실제 라인 + 식별 방식 관찰. 이 둘 되면 즉시 stop.
- 같은 파일/함수 두 번 읽기 금지. **도구 호출 5 회 이내 권장**.

## 금지
- 관찰하지 않은 테이블명/함수명/호출형식 지어내기 금지.
- 테이블 목록 전수 수집 금지 — 이미 본 것만 3~5 개 예시로.
- 추가 grep 으로 테이블을 더 찾지 말 것.
