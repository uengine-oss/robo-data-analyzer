# mini_project

Sample C project used as demo fixture for `universal_file_parser`.

## Files

- `src/*.c` — C source (target language, excluded from parsing)
- `CMakeLists.txt` — build config (unknown → DeepAgent)
- `Dockerfile` — container spec (library path)
- `.env` — env vars (library path)
- `config.yaml` — app config (library path)
- `package.json` — node meta (library path)
- `tests/test_config.yaml` — test config (library path)
- `deploy/k8s.yaml` — K8s manifest (library path)
- `deploy/values.yaml` — Helm values (library path)
