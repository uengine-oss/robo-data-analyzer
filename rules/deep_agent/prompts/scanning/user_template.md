## 프레임워크 패턴
이 프로젝트에서 **반복적으로 관찰되는 특징**을 3~6 문단으로 서술한다 (반복성이 핵심 기준).
예: 매크로 함수, 예외 처리, 기타 반복 패턴 등 — 예시에 국한되지 말고 실제로 반복되는 것은 무엇이든 기술.
핵심 매크로/함수 이름은 설명문 안에 자연스럽게 언급 가능.
단, 실체 목록 열거(특정 함수명 여러 개 쭉 나열)는 하지 말 것.

## DB 접근 패턴
이 프로젝트가 **실제 테이블/리소스를 어떻게 접근하는지** 의 특징을 3~6 문단으로 서술한다.
어떤 시그니처의 호출을 통해, 식별자는 어디에 어떤 형태로, 읽기/쓰기 의도는 어떻게 구분되는지,
결과/오류는 어떻게 판정되는지 등의 **메커니즘과 특징**에 집중한다.
특정 테이블명·SQL 키 등을 목록으로 열거하지 말 것 — 수집은 후속 링커의 역할.
